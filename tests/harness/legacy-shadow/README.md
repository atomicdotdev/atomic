# Archived shadow and early-shim scenarios

These scripts preserve the previous scenarios and assertions for coverage
review. They are **not active suites** and are not intended to run from here
(their original relative helper paths were retained).

See [the current shim coverage map](../shim.md) for replacement suites, changed
contracts and coverage boundaries. Use `run_all.sh` with the old suite name to
select the current replacements; do not interpret archived results as current
shim evidence.
